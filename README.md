# TRA_stand_robotic_arm_project-

Developed a wireless control system for a Kawasaki Industrial Robotic Arm showcased at TRA, Dubai. A tablet application transmitted commands via an HM-06 Bluetooth Low Energy (BLE) module integrated into the robot's control box, which then relayed the signals to the robotic arm's digital inputs to execute predefined operations. I was responsible for the hardware integration, communication setup, testing, and system validation,and Robotic arm Programm.
