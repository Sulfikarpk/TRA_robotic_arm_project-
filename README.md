# 🤖 Kawasaki Robotic Arm Wireless Control System

## 📖 Project Overview

This project was developed for the **Roads and Transport Authority (RTA), Dubai**, to demonstrate wireless control of a **Kawasaki Industrial Robotic Arm**. The system enables a tablet application to communicate with the robot through an **HM-06 Bluetooth Low Energy (BLE)** module integrated into the robot's control box. The received commands are forwarded to the robotic arm's digital input interface, allowing it to execute predefined movements and automated tasks.

I was responsible for the hardware integration, BLE communication setup, signal mapping, system testing, troubleshooting, and on-site deployment to ensure reliable operation during the exhibition.
